# [백엔드 실행 명령어]
# PowerShell
.\gradlew bootRun

# CMD (명령 프롬프트)
gradlew bootRun

기본 접속 URL: http://localhost:8080
Swagger UI: http://localhost:8080/swagger-ui/index.html


# [프론트엔드 실행 명령어]
cd frontend
npm run dev

기본 접속 URL: http://localhost:3000

--------------------------------------------------
[페이지 목록 및 주요 기능]
1. 원본 거래내역 & 마켓 시세 관리:
   - URL: http://localhost:3000/trade-history
   - 탭 구성: Table / Stats / BTC(코인시세) / 주문·시간별 합산(New)
   - [BTC / 코인시세 탭 (/trade-history?view=btc)]:
     * 지원 코인 9종: BTC, ETH, XRP, SOL, ADA, XLM, WLD, HYPER, ETC
     * 코인별 선택 탭 및 날짜별 시세(KRW) 조회
     * 선택 코인 개별 시세 동기화 및 9종 코인 일괄 동기화 (Upbit 연동)
     * 날짜별 가격 클릭 시 직접 수정(인라인 편집) 및 저장 기능

2. 주문 및 시간대별 거래 합산 페이지:
   - URL: http://localhost:3000/trade-summary (또는 /trade-history/summary)
   - 분할 체결(블록구매) 건을 1회 주문 또는 시간 범위 단위로 자동 합산하여 총 매수/매도 금액(예: 100만원)과 수량, 가중평균 단가 확인
   - 각 합산 행 클릭 시 분할 체결 블록 상세 아코디언 펼침 지원
