# [백엔드 실행 명령어]
# PowerShell
.\gradlew bootRun

# CMD (명령 프롬프트)
gradlew bootRun

기본 접속 URL: http://localhost:8080
Swagger UI: http://localhost:8080/swagger-ui/index.html


# [프론트엔드 실행 명령어]
cd frontend
npm run dev

기본 접속 URL: http://localhost:3000

--------------------------------------------------
[새로 추가된 페이지]
★ 주문 및 시간대별 거래 합산 페이지:
- URL 1: http://localhost:3000/trade-summary
- URL 2: http://localhost:3000/trade-history/summary

[주요 기능]
1. 분할 체결(블록구매) 통합: 100만원어치 매수 시 호가 잔량으로 인해 여러 행으로 쪼개진 건들을 1건으로 합산하여 총 100만원과 총 수량을 한눈에 확인
2. 시간 묶음 기준(Window) 선택:
   - ⭐ 동일 주문시간 (Ordered At) 일치
   - 10초 / 30초 / 1분 / 5분 / 10분 / 30분 / 1시간 이내 연속 체결
   - 동일 일자(하루 단위) / 선택 기간 전체 합산
3. 가중평균 체결단가 자동 계산 (총 금액 / 총 수량)
4. 각 합산 행을 클릭하면 포함된 원본 분할 체결 블록 상세 내역 아코디언 펼침 지원
5. CSV 내보내기 및 기존 원본 거래내역(/trade-history)과의 원클릭 이동 연동
